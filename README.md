# Snake Python

Latihan membuat game Snake dengan Python dan Pygame (mengikuti tutorial).

## Fitur

- Grid 20x20 pada jendela 500 px.
- Kontrol dengan tombol panah; ular bisa menembus tepi layar dan muncul di sisi seberang.
- Makanan muncul acak; ular bertambah panjang saat memakannya.
- Kotak pesan Tkinter saat game berakhir.

## Cara menjalankan

```bash
pip install pygame
python game.py
```

Tkinter harus tersedia di instalasi Python Anda.
